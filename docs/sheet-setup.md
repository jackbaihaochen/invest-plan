## 第 0 段: spike —— 先に通信だけ確かめる

クロスオリジンでブラウザから Apps Script を呼べるかは、**本番の URL でしか確かめられない**。
ここが駄目なら設計を変える必要があるので、先に測る。

1. Google ドライブで新しいスプレッドシートを作る。**共有はしない**（＝「自分のみ」のまま）。
2. 拡張機能 → Apps Script。エディタが開く。
3. `Code.gs` の中身を消して、[changes/sheet-backend/spike.gs](changes/sheet-backend/spike.gs) を貼る。
4. 左の歯車（プロジェクトの設定）→ スクリプト プロパティ → プロパティを追加
   - プロパティ: `TOKEN`
   - 値: 自分で決めた長いランダム文字列（例: パスワード生成器で 32 文字）
   - **この値は自分だけが持つ。**
5. 右上 デプロイ → 新しいデプロイ → 種類の選択（歯車）→ **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - デプロイ → 承認を求められるので許可
6. 出てきた **ウェブアプリ URL**（`…/exec` で終わる）を控える。

### 測る

7. https://jackbaihaochen.github.io/invest-plan/ を開く（**localhost では意味がない**。
   確かめたいのはこの origin から呼べるかどうかで、origin 自体が被験体）。
8. DevTools を開く（Mac: ⌥⌘I）→ Console。
9. [changes/sheet-backend/spike-check.js](changes/sheet-backend/spike-check.js) を貼り、
   先頭の `EXEC_URL` を 6 で控えた URL に差し替えて実行。
   `TOKEN` は空のままでよい —— **わざと違うトークンでも通信できるかは判る**。
10. 出力をそのまま渡す。`get` と `post` に `ok` または `denied` の JSON が入っていれば通信は生きている。

## 第 1 段: 本番のスクリプト

spike が通ってから。

1. 同じ Apps Script プロジェクトで、`Code.gs` の中身を
   [../apps-script/server.gs](../apps-script/server.gs) に差し替える。
2. エディタ左の「プロジェクトの設定」で **「appsscript.json マニフェスト ファイルをエディタで表示する」
   にチェック**。現れた `appsscript.json` を [../apps-script/appsscript.json](../apps-script/appsscript.json)
   の内容に差し替える。
   （これで Gmail は `gmail.readonly` だけになる。`GmailApp` を使うと、
   読むだけのはずが削除も送信もできる全権限を渡すことになる。）
3. デプロイ → デプロイを管理 → 鉛筆 → バージョン「新バージョン」→ デプロイ。
   **URL は変わらない。**

## 第 2 段: 基準価額メールの日次取り込み

1. エディタ左の時計アイコン（トリガー）→ トリガーを追加
   - 実行する関数: **`updatePrices`**
   - イベントのソース: 時間主導型 → 日タイマー → 午前 7〜8 時
2. 保存。Gmail の権限を求められるので許可。

> `updatePrices` は**トリガーからしか呼ばれない**。`doGet`/`doPost` からは絶対に呼ばない
> —— exec の URL は公開で、しかもあなたの権限で動く。メールに触る経路をそこに置くと、
> その URL があなたの受信箱を誰でも読める代理サーバになる。

## 第 3 段: ページ側

1. https://jackbaihaochen.github.io/invest-plan/ を開く。
2. いちばん下の **「多设备同步」** に
   - Apps Script の `/exec` URL
   - トークン（`TOKEN` に入れたのと同じ値）
3. 「保存并连接」。
4. サーバが空で手元にデータがあると、**どちらを残すか訊かれる**。答えは自分で選ぶ。
5. 他の端末でも 1〜3 を繰り返す。トークンは端末ごとに一度入力する。

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 「返回的不是 JSON」 | デプロイのアクセス権が「全員」になっていない |
| 「令牌不对」 | スクリプト プロパティの `TOKEN` と、ページに入れた値が違う |
| 「连不上服务器」 | URL が `/exec` で終わっているか。`/dev` は本人しか開けない |
| 価格が増えない | トリガーの実行履歴（時計アイコン → 実行数）でエラーを見る |

**つながらなくてもデータは消えない。** その端末に最後に同期できたぶんが残り、
画面上部に「いつのものか」が出る。
